# CRUD Fullstack React + Spring Boot

autor: @uzielthecreator
lenguaje: JavaScript y Java

---

## 📄 descripcion

este proyecto es un sistema CRUD fullstack desarrollado con React, Spring Boot y MySQL.

la aplicacion permite:

* crear personas
* visualizar registros
* eliminar datos
* conectar frontend y backend mediante una API REST

el proyecto fue desarrollado con una arquitectura moderna separando frontend y backend en carpetas independientes.

---

## ⚙️ caracteristicas

* CRUD completo
* arquitectura frontend/backend
* conexion con MySQL
* API REST con Spring Boot
* React Router
* componentes reutilizables
* diseño moderno responsive
* manejo de peticiones HTTP
* organizacion profesional de carpetas

## 🚀 ejecucion

### frontend

entra a la carpeta frontend:

```bash
cd Frontend
```

instala dependencias:

```bash
npm install
```

ejecuta el proyecto:

```bash
npm run dev
```

---

### backend

entra a la carpeta backend:

```bash
cd Backend
```

ejecuta Spring Boot desde IntelliJ o usando Maven:

```bash
mvn spring-boot:run
```
